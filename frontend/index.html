About the Project Architecture

5th-Semester Computer Science & Engineering Mini Project

Key Defense Point: The HTTPS Phishing Fallacy

In legacy phishing detection literature, the presence of HTTPS was considered a strong indicator of legitimacy. However, modern threat intelligence shows that over 80% of phishing websites now use valid HTTPS via free, automated Certificate Authorities (Let's Encrypt, Cloudflare, cPanel).

Confidentiality ≠ Authenticity: HTTPS guarantees encryption against local eavesdroppers. It does not verify that the website owner is benevolent. A criminal can securely encrypt the transmission of stolen credentials.
Our Solution: We engineered specialized features: HTTPS token spoofing detection, protocol-hostname mismatch, HTTPS interaction with free cloud hosts, and Shannon entropy analysis.
1

Feature Extraction Engine

Extracts 25 structural and lexical parameters without downloading remote HTML or executing malicious JavaScript, keeping execution safe and lightweight.

2

Machine Learning (Random Forest)

Ensemble classifier combining 100 decision trees to minimize variance and prevent overfitting on tabular URL patterns, outperforming single decision trees and logistic regression.

3

Explainable AI (XAI)

Eliminates the black-box dilemma by decomposing predictions into human-readable flags (e.g., brand typosquatting, DGA entropy, subdomain stacking).

4

Full-Stack & Extension Delivery

Delivered via FastAPI backend, responsive mobile-friendly PWA, and a companion Chrome/Brave Manifest V3 browser extension for live tab inspection.
